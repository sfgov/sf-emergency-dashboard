# SF Police Staffing Analysis

A data visualization tool for understanding police staffing patterns in San Francisco using incident data from SF OpenData.

## What It Shows

- **Incident volume by district**: See which districts have the highest call volume
- **Hourly patterns**: Understand when incidents peak throughout the day
- **Category breakdown**: View top incident categories citywide

## Data Source

Police incident data from [SF OpenData](https://data.sf.gov/resource/wg3w-h783) - SFPD incident reports.

## Development

```bash
npm install
npm run dev
```

## Tech Stack

- React + TypeScript + Vite
- date-fns for date handling
